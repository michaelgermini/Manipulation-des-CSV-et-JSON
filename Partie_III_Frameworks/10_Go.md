## Avantages de Go

### Pourquoi Go pour CSV/JSON?

| Aspect | Go | Python | Java | Rust |
|--------|-----|---------|------|------|
| **Vitesse compilation** | ⚡ Rapide | N/A | ⚠️ Lent | ⚠️ Très lent |
| **Binaire single** | ✅ 10MB | ❌ Requires runtime | ❌ JVM | ✅ 5MB |
| **Performance runtime** | ⚡⚡ | ⚠️ Interprété | ⚡ VM | ⚡⚡⚡ |
| **Concurrence** | ✅ Goroutines | ⚠️ GIL | ✅ Threads | ✅ Tokio |
| **Stdlib CSV/JSON** | ✅ Excellente | ✅ Bonne | ⚠️ Verbose | ✅ Bonne (serde) |
| **Apprentissage** | 🟢 Rapide | 🟢 Très rapide | 🟡 Modéré | 🔴 Difficile |

### Philosophie Go

> "Make it work, make it right, make it fast — in that order"

**Avantages clés** :
- ✅ Compilation = Binaire unique, pas de dépendances
- ✅ Stdlib robuste (encoding/csv, encoding/json inclus)
- ✅ Goroutines lightweight pour parallélisation
- ✅ Zero-allocation patterns possibles
- ✅ Cross-compile facile (Linux/Mac/Windows)

## CSV avec encoding/csv

### Setup minimal

```go
package main

import (
	"encoding/csv"
	"fmt"
	"os"
)

func main() {
	// Ouvrir fichier
	file, err := os.Open("data.csv")
	if err != nil {
		panic(err)
	}
	defer file.Close()

	// Créer lecteur CSV
	reader := csv.NewReader(file)

	// Lire tous les records
	records, err := reader.ReadAll()
	if err != nil {
		panic(err)
	}

	// Traiter
	for _, record := range records {
		fmt.Println(record)  // []string
	}
}
```

### Lecture ligne par ligne

```go
package main

import (
	"encoding/csv"
	"fmt"
	"os"
)

func main() {
	file, err := os.Open("huge.csv")
	if err != nil {
		panic(err)
	}
	defer file.Close()

	reader := csv.NewReader(file)
	reader.Comma = ','           // Délimiteur
	reader.FieldsPerRecord = -1  // Flexible number of fields

	// Lire header (première ligne)
	headers, err := reader.Read()
	if err != nil {
		panic(err)
	}
	fmt.Println("Headers:", headers)

	// Traiter chaque ligne
	lineNumber := 1
	for {
		record, err := reader.Read()
		if err != nil {
			break  // EOF
		}

		// Process line
		fmt.Printf("Line %d: %v\n", lineNumber, record)
		lineNumber++
	}
}
```

### Écriture CSV

```go
package main

import (
	"encoding/csv"
	"os"
)

func main() {
	// Créer fichier
	file, err := os.Create("output.csv")
	if err != nil {
		panic(err)
	}
	defer file.Close()

	// Writer CSV
	writer := csv.NewWriter(file)
	defer writer.Flush()

	// Écrire header
	writer.Write([]string{"ID", "Name", "Email"})

	// Écrire données
	data := [][]string{
		{"1", "Alice", "alice@example.com"},
		{"2", "Bob", "bob@example.com"},
	}
	writer.WriteAll(data)
}
```

## JSON avec encoding/json

### Parsing simple

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
)

func main() {
	jsonStr := `{"id":1,"name":"Alice","email":"alice@example.com"}`

	// Map (untyped)
	var data map[string]interface{}
	err := json.Unmarshal([]byte(jsonStr), &data)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println(data["name"])  // Alice
}
```

### Avec structures (recommended)

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	ID    int    `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email"`
}

func main() {
	jsonStr := `{"id":1,"name":"Alice","email":"alice@example.com"}`

	var user User
	json.Unmarshal([]byte(jsonStr), &user)

	fmt.Printf("%+v\n", user)
	// {ID:1 Name:Alice Email:alice@example.com}
}
```

### Tags avancés

```go
type Product struct {
	ID       int     `json:"id"`
	Name     string  `json:"product_name"`
	Price    float64 `json:"price,omitempty"`      // Omit if zero
	Internal string  `json:"-"`                     // Never marshal
	Active   bool    `json:"active,string"`         // Convert to string
}
```

### Écriture JSON

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	ID    int    `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email"`
}

func main() {
	user := User{ID: 1, Name: "Alice", Email: "alice@example.com"}

	// Compact
	data, _ := json.Marshal(user)
	fmt.Println(string(data))
	// {"id":1,"name":"Alice","email":"alice@example.com"}

	// Pretty-print
	data, _ = json.MarshalIndent(user, "", "  ")
	fmt.Println(string(data))
	// {
	//   "id": 1,
	//   "name": "Alice",
	//   "email": "alice@example.com"
	// }
}
```

## Parsing avec structures

### Conversion de types

```go
type Person struct {
	ID       string    `json:"id"`
	Name     string    `json:"name"`
	Age      int       `json:"age"`
	Salary   float64   `json:"salary"`
	Active   bool      `json:"active"`
	Created  time.Time `json:"created"`
	Tags     []string  `json:"tags"`
}

func main() {
	jsonStr := `{
		"id": "001",
		"name": "Alice",
		"age": 28,
		"salary": 50000.50,
		"active": true,
		"created": "2025-01-15T10:30:00Z",
		"tags": ["developer", "python"]
	}`

	var person Person
	json.Unmarshal([]byte(jsonStr), &person)

	fmt.Printf("%+v\n", person)
	// {ID:001 Name:Alice Age:28 Salary:50000.5 Active:true Created:2025-01-15 10:30:00 +0000 UTC Tags:[developer python]}
}
```

### Structs imbriquées

```go
type Company struct {
	ID       string    `json:"id"`
	Name     string    `json:"name"`
	Employees []Employee `json:"employees"`
}

type Employee struct {
	Name  string `json:"name"`
	Email string `json:"email"`
	Dept  string `json:"department"`
}

func main() {
	jsonStr := `{
		"id": "acme",
		"name": "ACME Corp",
		"employees": [
			{"name": "Alice", "email": "alice@acme.com", "department": "IT"},
			{"name": "Bob", "email": "bob@acme.com", "department": "HR"}
		]
	}`

	var company Company
	json.Unmarshal([]byte(jsonStr), &company)

	for _, emp := range company.Employees {
		fmt.Printf("%s (%s)\n", emp.Name, emp.Dept)
	}
}
```

## Gestion d'erreurs

### Pattern élégant

```go
package main

import (
	"encoding/csv"
	"fmt"
	"log"
	"os"
	"strconv"
)

type Record struct {
	ID    int
	Name  string
	Value float64
}

func parseCSVLine(record []string) (*Record, error) {
	if len(record) < 3 {
		return nil, fmt.Errorf("not enough fields: expected 3, got %d", len(record))
	}

	id, err := strconv.Atoi(record[0])
	if err != nil {
		return nil, fmt.Errorf("invalid ID: %w", err)
	}

	value, err := strconv.ParseFloat(record[2], 64)
	if err != nil {
		return nil, fmt.Errorf("invalid value: %w", err)
	}

	return &Record{
		ID:    id,
		Name:  record[1],
		Value: value,
	}, nil
}

func main() {
	file, _ := os.Open("data.csv")
	defer file.Close()

	reader := csv.NewReader(file)
	headers, _ := reader.Read()
	fmt.Println("Headers:", headers)

	lineNum := 1
	for {
		record, err := reader.Read()
		if err != nil {
			break
		}

		parsed, err := parseCSVLine(record)
		if err != nil {
			log.Printf("Line %d: %v (skipping)", lineNum, err)
			lineNum++
			continue
		}

		fmt.Printf("Line %d: %+v\n", lineNum, parsed)
		lineNum++
	}
}
```

## Pipelines et streaming

### Map-Filter-Reduce

```go
package main

import (
	"encoding/json"
	"fmt"
	"strings"
)

type User struct {
	ID    int    `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email"`
	Age   int    `json:"age"`
}

func main() {
	jsonData := `[
		{"id":1,"name":"Alice","email":"alice@example.com","age":28},
		{"id":2,"name":"Bob","email":"bob@example.com","age":35},
		{"id":3,"name":"Charlie","email":"charlie@example.com","age":42}
	]`

	var users []User
	json.Unmarshal([]byte(jsonData), &users)

	// Filter: age > 30
	var filtered []User
	for _, u := range users {
		if u.Age > 30 {
			filtered = append(filtered, u)
		}
	}

	// Map: extract names, uppercase
	var names []string
	for _, u := range filtered {
		names = append(names, strings.ToUpper(u.Name))
	}

	fmt.Println(names)  // [BOB CHARLIE]

	// Reduce: count
	count := len(filtered)
	fmt.Println("Count > 30:", count)  // 2
}
```

### Goroutines pour parallélisation

```go
package main

import (
	"encoding/csv"
	"fmt"
	"os"
	"strconv"
	"sync"
)

func processRecord(record []string, results chan<- int, wg *sync.WaitGroup) {
	defer wg.Done()

	if len(record) < 2 {
		return
	}

	val, err := strconv.Atoi(record[1])
	if err != nil {
		return
	}

	results <- val
}

func main() {
	file, _ := os.Open("data.csv")
	defer file.Close()

	reader := csv.NewReader(file)
	records, _ := reader.ReadAll()

	results := make(chan int, len(records))
	var wg sync.WaitGroup

	// Traiter en parallèle
	for _, record := range records[1:] {  // Skip header
		wg.Add(1)
		go processRecord(record, results, &wg)
	}

	go func() {
		wg.Wait()
		close(results)
	}()

	// Aggreger résultats
	total := 0
	for val := range results {
		total += val
	}

	fmt.Println("Total:", total)
}
```

## Optimisations et performance

### Buffered I/O

```go
package main

import (
	"bufio"
	"encoding/csv"
	"os"
)

func main() {
	file, _ := os.Open("huge.csv")
	defer file.Close()

	// Buffered reader (important pour perfs)
	scanner := bufio.NewScanner(file)
	reader := csv.NewReader(scanner)

	for {
		record, err := reader.Read()
		if err != nil {
			break
		}
		// Process
		_ = record
	}
}
```

### Preallocat memory

```go
package main

import (
	"encoding/csv"
	"os"
)

func main() {
	file, _ := os.Open("data.csv")
	defer file.Close()

	reader := csv.NewReader(file)

	// Preallocate slice
	records := make([][]string, 0, 1000)  // Capacity 1000

	for {
		record, err := reader.Read()
		if err != nil {
			break
		}
		records = append(records, record)
	}
}
```
